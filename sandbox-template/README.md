# Orbit Supply Co. storefront (agent sandbox)

This repository is the sandbox that AI agents change in the [Temporal agentic SDLC demo](https://github.com/temporal-sa/temporal-demo-agentic-sdlc). Each demo run works on its own `runs/...` branches; `main` and the `baseline` tag stay as they are.

Run the tests with `npm test`. Open `index.html` through any static file server to see the store.
